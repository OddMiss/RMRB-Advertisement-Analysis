# 人民日报广告分析（RMRB Analysis）

## 项目简介
对《人民日报》广告进行分析：识别含广告的版面、提取广告版块、执行 OCR，并借助大模型完成行业分类与内容解读。

## 处理流程
获取人民日报原始 PDF
→ 用计算机视觉／文本规则识别广告
→ 生成广告图片（整版／半版／CV 检测）
→ 提取广告版块并过滤重复
→ OCR 将图片转为文本
→ 用 AI 输出行业 + 广告类型 + 地区 + 分析

## 环境准备
1. 安装依赖：
   - `pip install -r requirements.txt`
2. 在 `Config/Config.py` 中配置数据路径：
   - `MAIN_PATH` / `EXTERNAL_PATH` / `EXTERNAL_PATH_LIST`
   - `MODEL_PATH`（PaddleOCR 模型目录）
3. 将 PaddleOCR 模型文件夹下载到 `MODEL_PATH`（参见 PaddleOCR 模型列表／发布页）：
   - https://github.com/PaddlePaddle/PaddleOCR/blob/main/doc/doc_en/models_list_en.md
   - https://github.com/PaddlePaddle/PaddleOCR/releases
   - 解压后请确保下列文件夹是 `MODEL_PATH` 的直接子目录：
   - `PP-DocLayout_plus-L_infer/`
   - `PP-OCRv5_server_det_infer/`
   - `PP-OCRv5_server_rec_infer/`
   - `PP-Chart2Table_infer/`
4. 创建 `Config/API.py`（已在 gitignore 中），填入大模型服务商与密钥：
   - `RMRBCore/RMRB_LLM_v5.py` 依赖此文件（`MODEL` 字典，含 URL/Models/Keys）
   - 示例：
     ```python
     MODEL = {
       "GEMINI": {
         "URL": "",  # GEMINI 不需要；多数其他 API 需要
         "Models": ["gemini-2.5-flash"],
         "Keys": ["<api-key>"]
       }
     }
     ```

## 数据目录结构
分析流程在数据根目录（由 `Config/Config.py` 指定）下读写。

```
{DATA_ROOT}/
  {YEAR}/
    {YYYYMMDD}/
      {YYYYMMDD}.pdf 或 {YYYYMMDD}{VV}.pdf
  {YEAR}_AD/
    {YYYYMMDD}/
      {YYYYMMDD}_{VV}_FAD.png          # 整版广告
      {YYYYMMDD}_{VV}_HAD.png          # 半版广告
      {YYYYMMDD}_{VV}_CV.png           # CV 检测出的版面
      {YYYYMMDD}_{VV}_{TYPE}_Block_{i}.png
      {image}.json                     # OCR + 大模型输出
    {YEAR}_Shape_Dict*.json            # 形状过滤与去重清单
```

## 运行分析（命令行）
Windows 用户可直接使用 `Scripts/`（或 `PortableScripts/`）下的 `.bat` 脚本。

1. **PDF 预处理（可选工具）**
   - `python RMRB_PDFTools.py`
   - 包含：MAC 检查、目录格式化、存在性检查、PDF 拆分、文件名修复。
2. **生成广告图片／版块**
   - `python RMRB_AD_Image_Generator.py`
   - 可选操作：
     - 生成广告图片（FAD/HAD/CV）
     - 提取广告版块（生成 `*_Block_*.png`）
     - 广告形状分析 + 重复检查（写出最终过滤清单）
3. **OCR**
   - `python RMRB_OCR.py`
   - 将 OCR 结果写入每张图片对应的 JSON。
4. **大模型摘要与分类**
   - `python RMRB_LLM.py`
   - 在同一批 JSON 中生成 `Summary~...` 字段。
5. **Notebook**
   - `RMRB_Analysis_v5.ipynb`
   - `RMRBCore/AD-Quant-Analysis.ipynb`、`AD_Text_Analysis.ipynb` 等。

# RMRB Strategy

这套研究框架只回答一个问题：**《人民日报》登了什么，对中国股市而言有没有可交易的信息？**

下文给出的答案是「有一点，但不够」。国家媒体的注意力中确实存在统计上可检出的反向信号，但它扛不住交易成本。这套框架的目标是诚实地得出这种结论，而不是画出一条好看的净值曲线——下面大部分代码存在的意义，就是识破回测惯用的那几种自欺方式。

## 模块

全部位于 `RMRBCore/` 下，纯 `.py` 文件，可独立导入。

| 模块 | 职责 |
| --- | --- |
| `RMRB_Dataset_v6.py` | 原始广告 JSON → 每日行业面板。兼容两套文件命名规范、重复创意筛除、多模型软投票、版面面积与版位权重、申万一级／二级切换、CSV 缓存。 |
| `RMRB_Factor_v6.py` | 声量占比（SoV）、季节性去趋势、滚动 z-score、活跃度掩码、缩尾、截面标准化、动量／波动率控制变量、正交化、因子合成。 |
| `RMRB_Backtest_v6.py` | 日频权重漂移组合引擎，显式执行延迟、双边成本、换手上限、重叠分批建仓；年化收益／夏普／索提诺／卡玛／最大回撤／信息比率／alpha／beta／Newey-West t 值。 |
| `RMRB_Research_v6.py` | Rank IC、持有期扫描、分位数阶梯、事件研究、领先滞后、样本内外切分、参数敏感性网格、置换检验、通缩夏普（deflated Sharpe）、分块自助法。 |
| `RMRB_Strategy_v6.py` | 策略注册表——每个策略都写明其经济学假设。保留原有的 `Daily_Z_Score_SoV`。 |
| `RMRB_Pipeline_v6.py` | 一键跑完整个研究流程，结果表写入 `Output/`。 |

```bash
python RMRBCore/RMRB_Pipeline_v6.py --rebuild --figures
```

`--level 2` 将截面切换到申万二级子行业，`--stage` 只跑单个阶段。数据根目录按 `RMRB_DATA_ROOT`、`RMRBData/`、`Config/Config.py` 中的盘符列表依次查找；数据本身不入库（已 gitignore）。

## 相比 Notebook 多做了什么

`AD-Quant-Analysis.ipynb` 和 `Industry-Analysis.ipynb` 都从 `AD_Industry_Count_Analysis.csv` 出发，而该文件把每则广告压缩成「取众数前二的行业、只算商业广告、各计一次」。这里找回了被丢掉的四类信息：

- **广告尺寸与版位。** 整版不等于半版版块，第 2 版也不等于第 16 版。两者都从数据里读出（`Shape_Dict` 的像素面积），作为投放金额与版面重要性的权重。
- **模型分歧。** 每则广告约有 15 个独立的大模型判断。软投票保留了取众数会丢弃的置信度信息；一级行业的平均一致率为 72%，二级为 58%。
- **政策渠道。** 公益／政策类广告此前被整体丢弃。它与企业买版是完全不同的经济信号，因此单独成表。
- **覆盖度。** 旧 CSV 合计 7,983 个行业计数；在重建后保留的 10,598 则广告上复现它自己的硬计数规则可得 10,466。差额主要来自同一版面的多则广告在「日期＋版号」这个键下相互覆盖。

抽取结果：10,598 则广告（整版 6,931、半版版块 1,436、CV 检测版块 2,231），143 则因重复创意被剔除，2014-01 至 2025-12 共 3,507 个出版日。每一则保留下来的广告都能映射到有效的申万行业。

## 方法

计数 → 声量占比 → 季节性去趋势 → 行业内 12 个月滚动 z-score → 活跃度掩码 → 缩尾 → 截面排序。

其中三步是针对具体失效模式的纠正：

1. **行业内 z-score** 修掉了拖垮 Notebook 策略的结构性偏差。银行每月都被报道、美容护理几乎从不，于是直接做原始截面排序会永远选中那几个天然安静的行业，最后变成一笔无意中押上的小盘 beta。把每个行业与其自身历史比较即可消除。
2. **季节性去趋势** 不是修饰步骤，见下文第 5 条的陷阱。
3. **活跃度掩码** 剔除过去一年月均不足 0.5 则广告的行业——在那里 z-score 只反映「这个月恰好有没有登过一则广告」。31 个行业中约 24 个通过。

回测把月末信号安排在次月**第二个**交易日执行，两次调仓之间权重随收益自然漂移，双边各收单边 15 bp 成本。

## 研究结论

**1. 反向信号真实存在，但很弱。** 当期注意力越高，下月收益越低。

| 面板 | Rank IC | ICIR | t（Newey-West） |
| --- | --- | --- | --- |
| 全部广告 | −0.0372 | −0.187 | −2.16 |
| 版位加权商业广告 | −0.0335 | −0.141 | −1.81 |
| 仅商业广告 | −0.0268 | −0.116 | −1.49 |
| 面积加权商业广告 | −0.0306 | −0.126 | −1.59 |
| 仅公益广告 | −0.0142 | −0.050 | −0.51 |
| 旧版硬计数 | −0.0185 | −0.090 | −1.14 |

样本为 132 个月度截面，每期约 24 个行业。重建后的面板把旧计数的 t 值大致翻了一倍。把每月的因子截面随机打乱后得到 p = 0.03，说明这个排序不是因子分布本身造成的假象。参数网格 18 个格点全部呈现假设方向的符号。

**2. 有效期是 1 至 3 个月。** 反向 IC 随持有期变化：1 个月 +0.037（t = 2.16），2 个月 +0.039（t = 2.55），3 个月 +0.034，6 个月归零，10 个月后转负。密集报道标记的是一个局部高点，在一个季度内消化，之后回归。

**3. 收益来自「回避」而非「选择」。** 五分位组合月均收益：Q1（最喧嚣）0.314%、Q2 0.459%、Q3 0.653%、Q4 0.635%、Q5（最沉寂）0.659%。阶梯单调（Spearman ρ = +0.90），但 Q3 以上基本走平——效应几乎全部来自曝光最多的那一组跑输。真正的交易不是买最沉寂的行业，而是不买最喧嚣的。

**4. 扛不住交易成本。** Q5−Q1 毛价差为每月 0.35%。市值中性组合只能拿到其中一半，且即便采用 3 个月分批建仓，年换手仍需 3.2 倍：

| 单边成本 | 0 bp | 5 bp | 10 bp | 15 bp | 20 bp | 30 bp |
| --- | --- | --- | --- | --- | --- | --- |
| 净年化收益 | +0.99% | +0.67% | +0.34% | +0.02% | −0.30% | −0.94% |

盈亏平衡点约在 15 bp，而这大致就是 A 股行业 ETF 的真实交易成本。纯多头版本同样没有显著跑赢等权行业组合：在对齐后的 2015-01 至 2025-12 区间，基准年化 4.01%，表现最好的注意力策略（`silent_winner`，冷门度与 1 个月动量的合成）为 4.74%，信息比率 0.14，t = 0.61。这是噪声。

**5. 宏观择时信号是一个季节性陷阱。** 这是最有价值的一条阴性结果。把商业广告总版面面积在 36 个月窗口上做 z-score，它与下月等权行业收益的相关系数为 −0.27（t = −3.0）；据此构建的仓位择时叠加层年化 10.82%，而基准仅 4.00%——超额 6.82%，t = 2.75。这是假象。人民日报广告量的季节性极强（12 月与 3 月是 2 月的四到五倍，单因素方差分析 p ≈ 1e-28），而 A 股收益本身也有日历效应（1 月 −3.3%，2 月 +3.2%）。加入月份固定效应控制后，相关系数降到 −0.11（t = −1.2），叠加层超额收益降到 2.82%（t = 1.53）。所谓 alpha 不过是两套日历恰好对上了。`macro_timing_exposure(deseason=True)` 因此设为默认值。

**6. 扩大广度反而失败。** 主动管理基本定律说信息比率随广度的平方根增长，所以从 31 个一级行业扩到 123 个申万二级子行业本应有帮助。结果恰恰相反：全样本月均仅约 74 则广告，摊到单个子行业后过于稀薄，IC 塌缩到 −0.011（t = −0.79），分位数阶梯失去单调性（ρ = +0.30），且样本内外符号翻转。信号衰减跑赢了广度增益。

**7. 该信号与价格动量基本独立**，且略强于动量：冷门度 IC +0.037（t = 2.16），对 1 个月动量正交化后 +0.028（t = 1.56），动量单独 +0.023（t = 0.92）。它并不是价格因子的换皮——只是不足以覆盖自身的换手成本。

**样本外。** 2021-01-01 的切分点在任何策略定型之前就已固定。反向 IC 样本内为 +0.043（t = 2.11），样本外为 +0.031（t = 1.02）：符号一致、量级相近，但显著性在更短的窗口里没能保住。

## 结论

《人民日报》所体现的国家媒体注意力，确实是一个可测量的行业反向信号，有效期 1 至 3 个月，效应集中在曝光最多的行业跑输这一侧。但它的效应量——首尾分位价差每月约 0.35%——低于在其衰减速度所要求的调仓频率下的收割成本。

它可以当作**风险叠加层**而非 alpha 来源使用：`hype_avoidance` 以 0.9 倍年换手把近期曝光激增的行业剔出等权组合，跟踪偏离在 0.13% 年化以内，因此若你本就想降低这部分暴露，这个偏离几乎是免费的。但把它作为独立策略部署，现有证据并不支持；通缩夏普也印证了这一点：在尝试过的 108 组配置下，实测夏普低于随机搜索本身预期能达到的水平。

两点必须说明的局限。回测交易的是申万行业**指数**，对于没有流动性 ETF 的行业，这会高估可实现收益。以及，132 个月度截面对于一个 2.2 的 t 值来说样本偏短——这是一个有启发性的发现，而非定论。
